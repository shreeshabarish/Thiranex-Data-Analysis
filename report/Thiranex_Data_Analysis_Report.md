# Thiranex Data Cleaning and Visualization Project

## 1. Introduction

This project focuses on cleaning, analyzing, and visualizing the Sample Superstore dataset using Python.

The main objective of this project is to understand the dataset, identify data quality issues, analyze sales and profit information, and create meaningful visualizations.

The project uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn for data processing, analysis, and visualization.

## 2. Dataset Description

The dataset used for this project is the Sample Superstore dataset.

The dataset contains 9,994 records and 21 columns.

The main information available in the dataset includes:

- Order details
- Customer information
- Shipping information
- Product information
- Sales
- Quantity
- Discount
- Profit
- Category and Sub-Category
- Region and State
- Order Date and Ship Date

The main numerical columns used for analysis are Sales, Quantity, Discount, and Profit.

## 3. Data Cleaning

The dataset was checked and cleaned before performing the analysis.

### Missing Values

The dataset was checked for missing values using Pandas. No missing values were found in the dataset.

### Duplicate Records

The dataset was checked for duplicate rows. No duplicate rows were found.

### Date Conversion

The `Order Date` and `Ship Date` columns were converted into datetime format. This allows the dates to be used correctly for time-based analysis.

### Data Types

The data types of all columns were checked to ensure that numerical, categorical, and date columns were stored in appropriate formats.

### Outlier Detection

The Interquartile Range (IQR) method was used to identify potential outliers in the Sales column.

The calculated values were:

- Q1: 17.28
- Q3: 209.94
- IQR: 192.66
- Lower Limit: -271.71
- Upper Limit: 498.93
- Number of potential outliers: 1,167

These values were identified as potential outliers and were analyzed rather than automatically removed.

## 4. Data Analysis

The cleaned dataset was analyzed to understand the relationship between sales, profit, quantity, discount, categories, sub-categories, and yearly sales.

### Sales and Profit by Category

The total sales and profit were calculated for each product category.

| Category | Sales | Profit |
|---|---:|---:|
| Furniture | 741,999.80 | 18,451.27 |
| Office Supplies | 719,047.03 | 122,490.80 |
| Technology | 836,154.03 | 145,454.95 |

Technology had the highest total sales and the highest total profit among the three categories.

Furniture had sales close to the other categories but generated considerably less profit.

### Sales by Year

Year-wise sales were calculated using the Order Date column. This analysis helps identify changes in sales over time.

### Sub-Category Analysis

Sales and profit were also analyzed for individual sub-categories. This helps identify which types of products contribute more to overall sales and profit.

### Correlation Analysis

The correlation between Sales, Quantity, Discount, and Profit was analyzed using a correlation matrix.

The main correlation values were:

- Sales and Profit: 0.48
- Discount and Profit: -0.22
- Quantity and Profit: 0.07

Sales and Profit show a moderate positive relationship. Discount has a weak negative relationship with Profit, while Quantity has very little relationship with Profit.
